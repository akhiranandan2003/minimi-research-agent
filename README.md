# Minimi Research Agent

The application source is in minimi-deploy/.

## Start locally

Run these commands from the repository folder:

    cd minimi-deploy
    npm install
    npm run dev

Then open http://localhost:5173. Follow minimi-deploy/README.md for Supabase setup, environment variables, tests, and deployment.

**Important:** keep .env private. Never commit API keys or the Supabase server-side secret.
